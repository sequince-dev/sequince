Developer guide
===============

These guides describe how to contribute to Sequince and the responsibilities
that apply to contributions. The pages include the maintained Markdown files
from the repository so updates appear here automatically.

* The :doc:`contribution guidelines <CONTRIBUTING>`
  cover development setup, building the documentation, code style, validation,
  and the pull request process.
* The :doc:`AI policy <AI_POLICY>`
  explains contributor ownership, review expectations, and validation of
  AI-assisted work.

For implementing new sampling components, see
:doc:`../user_guide/extending_sequince/index`.
